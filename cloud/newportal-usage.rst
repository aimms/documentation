Usage
=====

The **Usage** page gives all users a view of the features and quotas
included in their AIMMS Cloud Platform contract, if one is configured
for their account.

.. note::
   Not every account has a contract or quotas configured. Accounts
   without one will see limited or no information on this page.

.. note::
   This page is distinct from the *Usage* tab on the
   :doc:`Sessions <newportal-sessions>` page, which shows session
   activity over time rather than contract information.

Features
--------

The **Features** section lists the features available under your
account's contract. For example:

- IDE AI Assistant
- Portal AI Assistant — grants access to SENSAI within the Portal
- SENSAI Apps

Each feature has an information icon with a short description of what
it provides.

Quotas
------

The **Quotas** table lists any quotas configured for your account,
with the following columns:

- **Quota** — the name of the quota
- **Feature** — the feature the quota applies to
- **Limit** — the maximum allowed usage
- **Exceed action** — what happens when the limit is reached

If no quotas are configured for your account, this table will be
empty.

.. note::
   Active usage against configured quotas will be shown on this page
   in an upcoming release.
